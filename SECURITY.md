# Sicurezza

PADD WS è un gioco: non gestisce account, pagamenti o dati personali. Le parti più esposte sono la
versione web (<https://schermobianco.github.io/PaddWS/>), la lettura dei file di configurazione e
della classifica, e l'immagine della SD del Deck, un sistema Linux pronto all'uso.

## Versioni seguite

Si correggono solo l'ultima release e il ramo `main`.

## Come segnalare un problema

Non aprire una issue pubblica. Usa il modulo privato **Report a vulnerability** nella scheda
[Security](https://github.com/Schermobianco/PaddWS/security/advisories/new) del repository: lo vede
solo il maintainer. Scrivi la versione, la piattaforma, che cosa si può fare sfruttando il problema
e, se puoi, i passi per riprodurlo. Puoi scrivere in italiano o in inglese.

Il progetto è portato avanti nel tempo libero, quindi i tempi di risposta non sono garantiti. Una
volta corretto il problema, la segnalazione viene pubblicata con la release che lo risolve e chi
l'ha fatta viene ringraziato, se lo desidera.

# Security policy

PADD WS is a game: it handles no accounts, payments or personal data. The most exposed parts are
the web version (<https://schermobianco.github.io/PaddWS/>), the reading of the configuration and
high-score files, and the Deck SD card image, a ready-to-use Linux system.

## Supported versions

Only the latest release and the `main` branch get fixes.

## Reporting a vulnerability

Don't open a public issue. Use the private **Report a vulnerability** form in the
[Security](https://github.com/Schermobianco/PaddWS/security/advisories/new) tab of the repository:
only the maintainer can see it. Include the version, the platform, what an attacker could do and,
if you can, the steps to reproduce it. Italian or English are both fine.

The project is a spare-time effort, so response times aren't guaranteed. Once the issue is
fixed, the report is published with the release that fixes it, and the reporter is credited if
they wish.
